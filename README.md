# 3D Starlight Birthday Cake · 生日祝福网页

一个专为手机和桌面浏览器打造的 **3D 奶油星空生日蛋糕** 互动页面：
- **暗夜点灯沉浸式开场**：打开即见静谧夜空下纯净的奶油蛋糕轮廓，轻点屏幕瞬间点亮烛火，全屏白金粉星芒随之闪烁绽放并解锁八音盒音乐。
- **粉白金奶油美学**：珠光奶白粉渐变奶油蛋糕、平底金边白瓷托盘、3D 立体白色奶油裱花、丝带蝴蝶结、高阔轻盈的盘上断续微光细弧线，支持单指 360° 拖动旋转欣赏。
- **浪漫细蜡烛 / 可选数字蜡烛**：默认展示 3 支错落有致的浪漫细蜡烛（不暴露年龄）；也可通过参数切换 `1–99` 立体数字蜡烛。
- **离线内置八音盒**：纯 Web Audio 合成《祝你生日快乐》（八音盒 / 柔情钢琴 / 星空风铃三种音色），零海外 CDN 依赖，手机秒开。
- **许愿吹蜡烛 & 3D 烟花**：支持手机麦克风吹气感应熄灭（HTTPS 下可用），同时支持直接轻点烛火或按钮熄灭，触发白金粉 3D 烟花与专属祝福卡片。

## 使用教程一：免代码在线定制分享链接（最简单）

如果你只需要修改**寿星名字、蜡烛样式（浪漫细蜡烛 / 数字年龄蜡烛）、祝福语或内置音乐**：

1. 打开部署后的定制页：`https://<你的域名>/customize.html`（例如 `https://chu007.github.io/birthday-cake/customize.html`）。
2. 填写：
   - **寿星名字 / 昵称**（如 `Mia`）
   - **蜡烛样式**：默认 `浪漫细蜡烛（不显示年龄）`，也可切为 `立体数字蜡烛` 并输入 `1`–`99`
   - **祝福语**（吹灭蜡烛后在卡片中展示）
   - **背景音乐**：
     - 推荐选择内置音色（八音盒 / 柔情钢琴 / 星空风铃），无需加载外部文件；
     - 也可填入公开的 HTTPS 音频直链（`.mp3`）；
     - 若只是你自己本地试听或录屏，也可以选择本地 MP3 文件点击 **Preview** 预览（本地上传不会写入分享链接）。
3. 点击 **Generate Link** → **Copy**，把生成的链接发给对方即可。

> **为什么主链接里看不到定制表单？**
> 主页 `index.html` 保持纯净浪漫，只展示给寿星的专属画面；所有定制操作都在独立的 `customize.html` 完成。

## 使用教程二：Fork 仓库深度定制（含替换自己的本地 MP3）

如果你希望直接把自己的默认名字、祝福语或本地 MP3 歌曲打包上线，让别人打开主链接就听到你的 MP3：

1. 点击右上角 **Fork** 本仓库到你自己的 GitHub 账号。
2. （可选）如果你想用自己的 MP3 作为默认音乐：
   - 在仓库中新建文件夹 `public/music/`，把音频放进去（例如 `public/music/bgm.mp3`，建议压缩到 5MB 以内以保证手机加载速度）。
3. 打开并编辑 [`public/config.js`](public/config.js)：
   ```js
   window.BIRTHDAY_CONFIG = {
     name: "Mia",
     candles: "classic", // "classic" 或 "number"
     age: 18,
     wish: "生日快乐！愿你永远闪闪发光，自由快乐！",
     music: "musicbox",       // "musicbox" | "piano" | "chimes"
     audioUrl: "./music/bgm.mp3", // 若使用内置八音盒请保持为 ""
   };
   ```
4. 开启 GitHub Pages：
   - 进入仓库 **Settings → Pages**；
   - **Build and deployment → Source** 选择 **GitHub Actions**；
   - 推送一次提交（或在 **Actions** 中手动触发 `Deploy to GitHub Pages`），等待约 1 分钟即可生成 HTTPS 访问地址。

## 手机端体验提示

1. **HTTPS 是麦克风吹蜡烛的前提**：手机浏览器（iOS Safari / Android Chrome / 微信）规定只有 `https://` 网页才能请求麦克风权限；即使不授权麦克风，也可以直接**轻点烛火**或点击 **Blow Out** 吹灭蜡烛。
2. **微信内声音与吹气限制**：若在微信内置浏览器中打开，轻点屏幕点亮蜡烛后即可正常播放内置八音盒；如果个别机型微信限制了麦克风，直接点击屏幕上的火苗同样可以触发烟花。
3. **国内网络访问建议**：如果发现 `*.github.io` 在某些移动网络下打开偏慢，可将同一个 GitHub 仓库免费关联到 **Cloudflare Pages** 或 **Vercel**（构建命令 `npm run build`，输出目录 `dist`），国内访问会更稳定。
